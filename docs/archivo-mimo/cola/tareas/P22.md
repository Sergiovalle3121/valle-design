   `"-mx-2 bg-muted/40 px-2 type-micro font-semibold uppercase tracking-wide text-center text-muted-foreground"`
   - `uppercase` y `tracking-wide` son CSS, NUNCA `panel.label.toUpperCase()`: el texto del nodo es el nombre accesible del `role="group"` y `CadRibbonPanel.spec.ts:37` afirma `html.includes(panel.label)`.
