## Regla de actualización

Cada promoción debe enlazar una prueba que atraviese UI, motor y el límite
relevante. No se aceptan como evidencia única un documento de ejecución, una
prueba puramente unitaria, un fixture que intercepta toda la API o un benchmark
del índice sin navegador. Una regresión baja el estado; no se reescribe el
golden para conservar la etiqueta.
